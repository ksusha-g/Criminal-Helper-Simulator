# Criminal Helper Simulator
Гладилина Ксения + Куликова Екатерина

Проблема: отсутствие навыков разработки программного обеспечения (в контексте реальных условий на рынке) + учебное задание, которое необходимо выполнить.
Решение: создать учебный проект в виде игры, ориентированный на высокую оценку и получение опыта в цикле разработки программного обеспечения. Проект должен быть выполнен в установленный преподавателем срок.

Примерное описание: симулятор "бизнеса по помощи преступникам" в околосредневековом/фэнтези сеттинге. Игрок продает свои услуги клиентам-преступникам, помогая им подготовиться к делу или скрыть улики, за что получает валюту, которую может использовать для улучшения и покупки инструментов, используемых в работе (лучше инструменты = больше прибыль). В игре будет сюжет, развивающийся за счет действий игрока (насколько плохо/хорошо выполнил работу), принятые игроком решения так же имеют последствия.
Существующие примеры для вдохновения:
1) Хорошая пицца, отличная пицца - симулятор пиццерии. Обслуживание клиентов, индивидуальные заказы, улучшение оборудования
2) Beastfolk Barber - симулятор парикмахера. Игрок выбирает прическу клиенту на основе разговора с ним, что повлияет на сюжетную ветку персонажа. В конце дня игрок может увидеть результаты своих действий в местной соцсети
3) Coffee Talk - симулятор кофейни, где разветвление зависит не от диалогов, которые выбирает игрок, а от того, как он обслуживает клиентов
